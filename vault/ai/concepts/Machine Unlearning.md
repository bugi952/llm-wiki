## 주요 발전
- **2026-04-27**: legally protected context의 unlearning 검증을 behavioral signal로 수행 가능 [(원문)](https://arxiv.org/abs/2604.22191)
- **2026-04-27**: Privacy unlearning은 semantic relations이 아닌 gradient-driven ripple effects로 전파되어 shallow forgetting 초래 (2026-04-22) [(원문)](https://arxiv.org/abs/2604.22076)
- **2026-04-24**: Per-user proxy 삭제로 결정론적 언러닝 달성 (KL divergence ~0.21 nats, 82-89% 검증 통과율) [(원문)](https://arxiv.org/abs/2604.21571)
- **2026-04-21**: CAP: RL 기반 prompt 최적화로 폐쇄형 LLM에서 선택적 지식 망각 실현 (arXiv 2604.21251) [(원문)](https://arxiv.org/abs/2604.21251)
- **2025-10**: Downgrade to Upgrade: zeroth-order optimizer 사용으로 post-unlearning 양자화/fine-tuning 후에도 망각 효과 유지, robustness 향상 (arXiv:2510.00761) [(원문)](https://arxiv.org/abs/2510.00761)
- **2026-04-21**: PUBG: VLM unlearning 후 hallucination/refusal 문제 해결, privacy 보호하면서 정보성 있는 응답 유도 (2026-04-21) [(원문)](https://arxiv.org/abs/2506.02541)
- **2026-04-21**: 2026-04: 엔트로피 기반 토큰 가중치(ETW)로 정보 토큰 우선 언러닝, 모델 유틸리티 손실 감소 [(원문)](https://arxiv.org/abs/2604.17785)
- **2026-04-21**: REGLU: Representation space의 기하학적 성질 활용, LoRA 기반 언러닝에서 forget-retain trade-off 개선 [(원문)](https://arxiv.org/abs/2604.17396)
- **2026-04-21**: RASLIK: permutation-projection hashing + randomized antipodal search로 unlearning 데이터 검색 variance 감소 [(원문)](https://arxiv.org/abs/2604.16591)
- **2026-04-21**: 소프트웨어 품질보증 관점: unlearning test는 influence pathway coverage, debuggable diagnostics, cost-effective regression, black-box applicability 4가지 요구사항 충족 필요 [(원문)](https://arxiv.org/abs/2604.16536)
- **2025-10**: Attention Shifting (AS) 프레임워크: context 토큰 주의 약화+할루시네이션 저항성 응답 설계로 공격적/보수적 언러닝 균형 [(원문)](https://arxiv.org/abs/2510.17210)
- **2026-04-20**: Large Reasoning Model의 CoT 단계에 counterfactual 개입으로 논리적 유효성 유지하면서 선택적 정보 제거 가능, 기존 방식의 한계 극복 [(원문)](https://arxiv.org/abs/2604.15847)
- **2026-04-20**: LLM 언러닝의 4가지 동시 목표: ① 유해 지식 제거 ② 일반 유용성 보존 ③ 경계 개념 과다 거부 회피 ④ 적대 탐지 견고성. 기존 방법은 ①②만 다룸 [(원문)](https://arxiv.org/abs/2604.15482)
- **2026-04-19**: Depth-Aware Modulation by Projection (DAMP): 클래스별 represent 제거 via one-shot weight-surgery (classifier-head suppression 회피) [(원문)](https://arxiv.org/abs/2604.15166v1)
