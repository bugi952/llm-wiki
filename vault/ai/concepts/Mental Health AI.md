# Mental Health AI

## 정의


## 주요 발전
- **2026-04-27**: 대화형 정신과 intake에서 LLM 기반 적응형 정책(300회 인터뷰 세션)이 무작위·표준형식 baseline 대비 우수 [(원문)](https://arxiv.org/abs/2604.22067)
- **2026-04-27**: 입원 위험도 평가에서 LLM의 prompt sensitivity와 algorithmic bias 체계적 감시 필요성 입증 [(원문)](https://arxiv.org/abs/2604.22063)
- **2026-04-24**: 자발적 음성 녹음에서 인지 기능 저하의 바이오마커 식별 및 classification [(원문)](https://arxiv.org/abs/2502.03484)
- **2026-04-24**: CARE: 상담사 기반 실시간 응답 생성 엔진으로 히브리어·아랍어 등 저자원 언어에서 심리 위기 지원 자동화 [(원문)](https://arxiv.org/abs/2604.21352)
- **2026-04-21**: PsychBench(28,800 프로필): GPT-4o-mini~DeepSeek-V3에서 분산 압축(14-62%) 및 진단 임계값 이탈(36.66%) 발견. 임상 시뮬레이션의 신뢰성 기준 미달 [(원문)](https://arxiv.org/abs/2604.17359)
- **2026-04-21**: 제로 에그레스 온디바이스 LLM 배포로 군·교정·원격의료 환경에서 환자 프라이버시 보호 달성 [(원문)](https://arxiv.org/abs/2604.18302)
- **2026-04-21**: 감정 지원 대화에서 현실의 인간 지원자는 한 발화 내 여러 전략을 결합 사용 → All-in-One/One-by-One 생성 방식과 RL 기반 강화로 모델링 가능 [(원문)](https://arxiv.org/abs/2604.17972)
- **2026-04-21**: MHSafeEval: 역할 인식형 다중 상호작용 안전 평가로 상담 AI의 누적 임상 해악 진단 [(원문)](https://arxiv.org/abs/2604.17730)
- **2026-04-21**: CoPoLLM: cognitive distortion 진단·개입을 위한 LLM 프레임워크 [(원문)](https://arxiv.org/abs/2604.17178)
- **2026-04-21**: CogBiasESC dataset (arXiv:2604.17178): ESC에서 cognitive distortion 타입/강도/위험도 라벨링 [(원문)](https://arxiv.org/abs/2604.17178)
- **2026-04-21**: 자동 우울증 추정에 Normal-Inverse-Gamma 분포 기반 증거학습(EviDep) 적용 가능 (신호 손상/잡음 강건성) [(원문)](https://arxiv.org/abs/2604.16579)
