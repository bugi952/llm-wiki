## 주요 발전
- **2026-04-21**: MolClaw: 70개 스킬(tool 원자→workflow 검증→discipline 과학 원칙)로 약물 분자 평가/스크리닝/최적화 자동화. 30+ 전문 도메인 리소스 통합 [(원문)](https://arxiv.org/abs/2604.21937)
- **2026-02-03**: 13C NMR reversible deep learning: i-RevNet 기반 bijective blocks로 분자 구조-스펙트럼 양방향 변환, spectrum-to-structure의 one-to-many 특성 명시적 모델링 [(원문)](https://arxiv.org/abs/2602.03875)
- **2025-10-05**: 사전학습 ATOM으로 양자역학 계산 대체 → drug discovery 파이프라인 가속화 [(원문)](https://arxiv.org/abs/2510.05482)
- **2026-04-24**: 금속-유기 프레임워크 합성의 산업 확장성 LLM 예측으로 발견 후보의 실용적 트리아지 가속 [(원문)](https://arxiv.org/abs/2604.20899)
- **2026-04-21**: KinetiDiff: geometry-complete diffusion + real-time AutoDock Vina gradient로 ACVR1 inhibitor 생성. 10,000 샘플 중 9,997개 유효, reference 대비 19.2% 개선 (ΔG = -11.05 kcal/mol) [(원문)](https://arxiv.org/abs/2604.20886)
- **2026-04-21**: 보상 함수 기반 생성 모델의 훈련 프로세스 이해도 증대 [(원문)](https://arxiv.org/abs/2604.21830)
- **2026-04-24**: 멀티모달 LLM 기반 문헌 생물활성 데이터 자동 추출: 텍스트/표/이미지 통합 의미론 해석 [(원문)](https://arxiv.org/abs/2604.21508)
- **2026-04-21**: ConforNets: AlphaFold3의 Pairformer 잠재에 채널별 아핀 변환으로 미생물학적 컨포메이션 다양성 획득 (arXiv:2604.18559) [(원문)](https://arxiv.org/abs/2604.18559)
- **2026-04-21**: 알츠하이머병 치료제 발굴을 위해 천연 의약 화합물에 화학정보학 기반 예측 모델 적용. amyloid-beta, tau 단백질 축적 관련 약물 후보 스크리닝 [(원문)](https://arxiv.org/abs/2604.18316)
- **2026-04-21**: ConGA-PepPI 모델로 펩타이드-단백질 상호작용 예측 0.839 정확도, 0.921 AUROC. TC-PepGen으로 target-conditioned 펩타이드 생성 [(원문)](https://arxiv.org/abs/2604.18467)
- **2026-04-21**: Functional flow 기반 약동학 모델: 벡터 필드 학습으로 모집단 가상 코호트 생성 및 부분 관찰 환자 예측 가능 [(원문)](https://arxiv.org/abs/2604.17670)
- **2026-04-21**: LLM 기반 추론시간 검색(RosettaSearch)으로 단백질 설계 성공률 2.5배 개선, LigandMPNN 단일 통과 한계 극복 [(원문)](https://arxiv.org/abs/2604.17175)
- **2026-04-21**: 단일 세포 유전자 발현 모델(SAVE)로 미처리 조건 조합 시뮬레이션 가능, 신약 발견 가속화 [(원문)](https://arxiv.org/abs/2604.16776)
- **2026-04-21**: FRIGID 프레임워크: MassSpecGym에서 18% Top-1 정확도, NPLIB1에서 기존 최고 성능의 3배 달성 [(원문)](https://arxiv.org/abs/2604.16648)
- **2026-04-21**: Foundation Model 기반 분자 예측이 quantum/descriptor ML/geometric DL을 통합한 새 패러다임 형성 [(원문)](https://arxiv.org/abs/2604.16586)
