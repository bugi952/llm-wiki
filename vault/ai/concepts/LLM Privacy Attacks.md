# LLM Privacy Attacks

## 정의


## 주요 발전
- **2025-05-01**: Adversarial input의 공격 방식(prompt injection vs backdoor)에 관계없이 일관된 위상 시그니처가 표현 공간 전체에서 나타나는 일반적 특성 확인 [(원문)](https://arxiv.org/abs/2505.20435)
- **2024-11-04**: 분류 모델의 출력 레이블 공간을 DP 회피 공격 벡터로 활용, membership inference 리스크 증명 [(원문)](https://arxiv.org/abs/2411.04680)
- **2026-04-27**: Behavioral Canaries: RL fine-tuning 단계에서 preference data 미공개 사용을 trigger-conditioned behavior로 탐지 [(원문)](https://arxiv.org/abs/2604.22191)
- **2026-04-27**: Unlearning 방법의 direct retrieval, in-context learning, fine-tuning 공격에 대한 강건성 3단계 평가 (2026-04-22) [(원문)](https://arxiv.org/abs/2604.22076)
- **2026-04-24**: Unicode 표정 문자와 인코딩 변이를 이용한 익명성 우회 가능 (stylometric analysis 기반) [(원문)](https://arxiv.org/abs/2508.15840)
- **2026-04-24**: LoRA 어댑터와 사용자 프록시 분리로 모델 역추적/멤버십 추론 공격 완화 [(원문)](https://arxiv.org/abs/2604.21571)
- **2026-04-24**: 익명화 텍스트에서 문맥 기반 정보 추론으로 프라이버시 우회, target-subject 보호 시 non-target 노출 문제 [(원문)](https://arxiv.org/abs/2604.21211)
- **2026-04-24**: Federated LLM의 sparse/non-orthogonal gradient 특성이 MIA에 취약. 4개 벤치마크·4개 LLM 평가로 privacy drift 규명 [(원문)](https://arxiv.org/abs/2604.21197)
- **2026-04-21**: Entropy-Memorization Linearity: 데이터 엔트로피와 LLM 암기량 간 선형 상관 관계 발견 [(원문)](https://arxiv.org/abs/2507.06056)
- **2026-04-21**: Gibberish bias: 높은 문자 엔트로피 시크릿이 BPE tokenization으로 낮은 토큰 엔트로피가 되어 Code LLM에서 더 쉽게 암기되는 현상 [(원문)](https://arxiv.org/abs/2604.17814)
