## 주요 발전
- **2026-04-22**: 신경망이 가변 길이 연산 수열로 프로그램을 표현하여 고정 연산 수 제약 제거. Latent Adaptation Network 기반의 차별화된 학습 메커니즘 [(원문)](https://arxiv.org/abs/2604.18907)
- **2026-04-21**: 구조 기반 진화 연산자로 기존 end-to-end 생성의 시맨틱 제약 극복 — 다양하지만 초기에 무효인 변이체도 LLM 수리로 고품질 휴리스틱 도출 가능 [(원문)](https://arxiv.org/abs/2604.16420)
- **2026-04-21**: test-time 프레임워크로 컴팩트한 확률 프로그램 구성; GPU 계산 비용 대폭 절감 [(원문)](https://arxiv.org/abs/2604.17290)
- **2026-04-21**: 조합 최적화는 LLM 없이 순수 신경망(LEHD + SA + POMO + Beam Search)으로도 문제 해결 알고리즘 학습 가능 [(원문)](https://arxiv.org/abs/2604.16581)
- **2026-04-20**: LLM 가이드 진화 탐색(EVIL)으로 Python/NumPy 프로그램 자동 합성. 단일 발견 알고리즘이 모든 데이터셋에 제로샷 일반화 [(원문)](https://arxiv.org/abs/2604.15787)
