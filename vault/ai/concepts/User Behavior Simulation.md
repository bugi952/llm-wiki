# User Behavior Simulation

## 정의


## 주요 발전
- **2025-10**: 32M 설문 응답 시뮬레이션에서 방법론 간 개별/하위집단 정렬 차이 발견, reasoning output 효과 일관적 아님 [(원문)](https://arxiv.org/abs/2510.11586)
- **2026-02-04**: SemaPop: LLM 파생 persona 텍스트를 semantic embedding으로 인코딩하여 GAN 기반 population synthesis 조건화, marginal regularization으로 통계적 제약 유지 [(원문)](https://arxiv.org/abs/2602.11569)
- **2026-04-21**: 페르소나 간 상호작용 그래프 구조 보존으로 실제 소셜 네트워크 시뮬레이션 가능 [(원문)](https://arxiv.org/abs/2507.14922)
- **2026-04-21**: OPeRA: 온라인 쇼핑 행동 시뮬레이션 평가용 실제 사용자 데이터셋(관찰, 페르소나, 근거, 행동) 공개 (2026-04-21) [(원문)](https://arxiv.org/abs/2506.05606)
- **2026-04-21**: HORIZON 벤치마크: 54M 사용자·35M 항목의 크로스도메인 행동 모델링 (Amazon Reviews 기반) [(원문)](https://arxiv.org/abs/2604.17259)
- **2026-04-21**: 명시적 사용자 의도 없는 상황에서 공명과 문제 제시를 통한 대화 유도 [(원문)](https://arxiv.org/abs/2604.18375)
- **2025-09-13**: silicon samples (LLM 합성 인간 응답)의 높은 분석적 유연성으로 인해 신뢰성 낮음 [(원문)](https://arxiv.org/abs/2509.13397)
- **2025-02-20**: 분포 시프트 정렬(DSA) 방법으로 LLM이 훈련 데이터보다 실제 설문 분포에 더 정확하게 수렴 [(원문)](https://arxiv.org/abs/2510.21977)
- **2026-04-20**: LLM이 인간의 방향성 효과는 재현하나 효과 크기와 조절 패턴은 인간과 달라 대리성 제한적 [(원문)](https://arxiv.org/abs/2604.15329)
- **2026-04-19**: Policy-Guided Hybrid Simulation: 행동 궤적에서 정책 채굴로 LLM 추론과 ML 피팅 정렬 [(원문)](https://arxiv.org/abs/2604.15190v1)
