# Graph-LLM Integration

## 정의


## 주요 발전
- **2026-04-25**: 문서 수준 구조적·의미론적 추론으로 LLM의 주의력 확산(attention dilution) 문제 해결 [(원문)](https://arxiv.org/abs/2604.21885v1)
- **2026-04-24**: 다중 스케일 탐색 도구와 LLM 추론을 그래프 구조에 맞춰 통합 [(원문)](https://arxiv.org/abs/2604.05846)
- **2026-04-21**: MODEE: Multimodal (text + graph) 접근으로 LLM의 lost-in-the-middle 현상 해결, 문서 수준 구조적 추론 가능 (arXiv:2604.21885) [(원문)](https://arxiv.org/abs/2604.21885)
- **2026-04-22**: K-hop 검색의 하드웨어 최적화로 증거 기반 추론의 확장성 개선 [(원문)](https://arxiv.org/abs/2604.18913)
- **2026-04-21**: 2단계 의미 기반 검색: 공출현 가중치 + 유사도 지도 결합으로 생성 품질 향상 (2026-04) [(원문)](https://arxiv.org/abs/2604.16350)
- **2026-04-21**: LLM이 그래프 정보를 간과하는 경향이 있으며, 주의 재분배(Look), 피드포워드 네트워크 정보 재주입(Remember), 대조학습(Contrast)으로 개선 가능 [(원문)](https://arxiv.org/abs/2604.17897)
- **2026-04-21**: DuConTE: 이중 입도 텍스트 인코더로 word-token과 node 레벨에서 순차적 의미 추출 및 토폴로지 제약 적용 [(원문)](https://arxiv.org/abs/2604.17411)
- **2026-04-21**: HopRank: 텍스트 속성 그래프에서 LLM 기반 링크 예측으로 자기지도학습 노드 분류 수행 [(원문)](https://arxiv.org/abs/2604.17271)
- **2026-04-21**: Graph 기반 agent communication으로 MoA 대비 intra-agent communication 및 response integration 개선 [(원문)](https://arxiv.org/abs/2604.17148)
