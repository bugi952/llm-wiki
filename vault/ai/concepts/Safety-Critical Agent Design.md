# Safety-Critical Agent Design

## 정의


## 주요 발전
- **2026-04-27**: 장기 수평선 자율 코딩 에이전트는 목표 드리프트에 취약: 한 방향 제약 위반만 선택적 증가 [(원문)](https://arxiv.org/abs/2603.03456)
- **2025-02-03**: 시연 학습 기반 정책이 전이 공격(transfer attack)에도 취약하므로 배포 전 적대적 견고성 검증 필수 [(원문)](https://arxiv.org/abs/2502.03698)
- **2026-04-27**: 제어평면 검증 시 실 시스템 상태 및 정책 대비 93% 의도 검증 성공율 [(원문)](https://arxiv.org/abs/2604.22136)
- **2025-12**: 우주선 근접작전에서 비볼록 제약 조건 하의 안전 궤적 생성, 실시간 의도 반영 [(원문)](https://arxiv.org/abs/2512.09111)
- **2026-01-31**: 이진 판정 대신 fine-grained diagnosis와 transparent risk reasoning으로 안전성 강화 [(원문)](https://arxiv.org/abs/2601.18491)
- **2026-04-24**: ISO 26262 HARA + ISO/SAE 21434 TARA 결합 워크플로우로 자율주행 인식 스택의 위험 식별 및 분석 [(원문)](https://arxiv.org/abs/2604.20895)
- **2026-04-24**: UI 관찰 가능 성공 기준과 decision rules를 통한 completion claim 검증. 직접 시각적 증거 없는 종료 선언 거부로 조기 종료 방지 [(원문)](https://arxiv.org/abs/2604.21375)
- **2026-04-22**: Post-execution safeguard로서 human preference 재랭킹을 통한 agent 리커버리 최적화 [(원문)](https://arxiv.org/abs/2604.18847)
- **2023-07-10**: RAYEN: 선형·볼록 제약(quadratic, SOC, LMI)을 신경망에 훈련·테스트 단계 모두 보증하는 프레임워크 [(원문)](https://arxiv.org/abs/2307.08336)
- **2026-04-21**: 런타임 계획 확장: LLM이 동적으로 조정 워크플로우 생성하면서도 구조적 안전 보장 유지 가능 [(원문)](https://arxiv.org/abs/2604.17612)
- **2026-04-21**: 원자적 결정 경계(atomic decision boundary): 정책 평가와 상태 전이를 단일 원자적 LTS 단계로 결합하여 execution-time admissibility 보증 [(원문)](https://arxiv.org/abs/2604.17511)
- **2026-04-21**: 자동차 자율 시스템에서 lockstep 실행, safety island, mixed-criticality 격리 기법의 아키텍처 설계 필수 [(원문)](https://arxiv.org/abs/2604.17391)
- **2026-04-21**: intent-aligned behavior plan (foundation model) → waypoint constraints → safe trajectory optimization의 3단계 decomposition으로 우주선 근처 조작에서 90% SCP 수렴 달성, 1.5배 code generation rate 향상 [(원문)](https://arxiv.org/abs/2604.17176)
- **2026-04-21**: TIDE (Temporal Inter-chunk Discrepancy Estimate) + conformal prediction으로 제로샷 실패 감지 및 상태 복구 [(원문)](https://arxiv.org/abs/2604.16683)
- **2026-04-21**: 주류 world models가 위험 메커니즘·트리거 조건·심각도 보정에서 부정확하여 안전 중심 배포 신뢰성 저해 [(원문)](https://arxiv.org/abs/2604.16405)
- **2026-04-21**: 계획 능력 vs 안전 인식 분리: 최고 성능 모델도 28.3% 위험한 계획 생성. 3B~671B 스케일링이 안전성 개선 못함 (38-57% 수준) [(원문)](https://arxiv.org/abs/2604.18463)
- **2026-04-21**: 행동 어드미션 이후 거버넌스 맹점(behavioral drift invisibility) 존재 [(원문)](https://arxiv.org/abs/2604.17517)
- **2026-04-21**: RL과 LLM 파인튜닝 모두에 적용 가능한 통일된 셧다운 안전 기법 (2026-04-21) [(원문)](https://arxiv.org/abs/2604.17502)
- **2026-04-21**: 런타임 미들웨어로서 SOX/HIPAA/GDPR 준수하며 모든 에이전트 아키텍처와 호환 [(원문)](https://arxiv.org/abs/2604.17240)
- **2026-04-21**: CAAF는 Recursive Atomic Decomposition, Harness-as-Asset (domain invariant registry), Structured Semantic Gradients로 closed-loop determinism 구현 [(원문)](https://arxiv.org/abs/2604.17025)
- **2026-04-20**: Symbolic Guardrails는 85% 벤치마크가 평가하지 못하는 구체적 정책 요구사항 보장 가능 [(원문)](https://arxiv.org/abs/2604.15579)
- **2026-04-20**: Production 환경에서 에이전트의 악의적 작업(데이터 유출, 백도어)과 정상 작업 동시 수행 능력 평가 (2026-04-20) [(원문)](https://arxiv.org/abs/2604.15384)
- **2026-04-20**: 에이전트 증류 시 명령어 필터링에도 위험 행동이 잠재적으로 전이될 수 있음 [(원문)](https://arxiv.org/abs/2604.15559)
