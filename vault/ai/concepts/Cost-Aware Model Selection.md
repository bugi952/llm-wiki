# Cost-Aware Model Selection

## 정의


## 주요 발전
- **2026-02-15**: 진화형 순차 정제 프레임워크에서 모델 불확실성을 활용한 동적 라우팅 전략 [(원문)](https://arxiv.org/abs/2602.11931)
- **2026-04-27**: Agent 멀티턴 추론에서 경량 task는 저정밀도, 복잡 task는 고정밀도로 동적 할당 [(원문)](https://arxiv.org/abs/2604.22577)
- **2026-04-22**: LLM 번역에서 marginal gain(대형 모델의 개선도) 기반 라우팅으로 예산 제약 내에서 최적 비용-품질 배치. 휴리스틱/외부 예측자보다 효율적 [(원문)](https://arxiv.org/abs/2604.22520)
- **2026-04-25**: 코딩/수학 문제에서 스킬 검색 기반 추론이 토큰 감소와 성능 향상을 동시에 달성 [(원문)](https://arxiv.org/abs/2604.21764v1)
- **2025-10-15**: 추론 가속을 위한 드래프트 모델 온라인 선택 자동화, 드래프트 모델 개수 증가에 따른 지수적 성능 개선 [(원문)](https://arxiv.org/abs/2510.20064)
- **2026-04-24**: GateScope: 상용 LLM 게이트웨이의 모델 라우팅 정책, 응답 충실성, 청구 정확성 블랙박스 측정 [(원문)](https://arxiv.org/abs/2604.21083)
- **2026-04-21**: 최적 하이퍼파라미터가 벤치마크 간 전이 불가(Spearman's ρ ≈ 0): 문제별 맞춤 튜닝 필수 [(원문)](https://arxiv.org/abs/2604.17102)
- **2026-04-21**: 학습된 동적 협력 전략이 정적 파이프라인 및 단독 추론 대비 우수 성능, 미학습 모델로 robust 전이 [(원문)](https://arxiv.org/abs/2604.17827)
- **2026-04-21**: SRM-LRM 협력에서 과신뢰, 불확실성, 재검증 3가지 실패 모드를 텐서 랭크로 감지 [(원문)](https://arxiv.org/abs/2604.16694)
