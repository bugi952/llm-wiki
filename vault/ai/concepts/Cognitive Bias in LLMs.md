# Cognitive Bias in LLMs

## 정의


## 주요 발전
- **2026-02-01**: LLM baseline: attenuated loss aversion, weak herding, near-zero disposition effects (인간 기준 미달), calibration 후 coherent shift 달성 [(원문)](https://arxiv.org/abs/2602.01022)
- **2025-01-15**: LLM 훈련 과정에서 특정 국가(특히 아시아) 문화 편향이 나타나는 시점 규명 [(원문)](https://arxiv.org/abs/2604.21751v1)
- **2026-04-24**: Framing effect in code review: 6개 LLM에서 버그 프리 프레이밍이 가장 강력한 편향 유발 (체계적 현상) [(원문)](https://arxiv.org/abs/2603.18740)
- **2026-04-21**: 창의성 평가 시 LLM(ChatGPT-4o)이 자신의 생성 스타일과 유사한 응답을 더 높이 평가하는 자기선호 편향 발견 [(원문)](https://arxiv.org/abs/2604.20569)
- **2026-04-21**: Culture-Related Open Questions(CROQ) 분류법으로 LLM의 regional preference 측정. 입력 언어와 공식 언어 일치 시 편향 심화. [(원문)](https://arxiv.org/abs/2604.21751)
- **2026-04-24**: 직접 질문 회피와 다중턴 비판적 압박 간 LLM 의견의 불일치 실증 [(원문)](https://arxiv.org/abs/2604.21564)
- **2026-04-24**: 정책 분석과 경제 리포팅에서 LLM의 체계적 이데올로기 편향이 인과 판단에 영향 [(원문)](https://arxiv.org/abs/2604.21334)
- **2026-04-21**: 구조화된 컨텍스트 태그가 특정 역할 정보 선호 편향을 내재화 [(원문)](https://arxiv.org/abs/2508.15815)
- **2025-05-16**: 다중 편향 조합이 LLM 안정성에 영향. 단일 편향 강화에도 불구하고 앙상블 편향에 여전히 취약 [(원문)](https://arxiv.org/abs/2505.16522)
- **2024-08-09**: 역할 연기 규모 실험으로 LLM 내부 가치 지향성(value orientation)의 강력한 편향 확인 [(원문)](https://arxiv.org/abs/2408.09049)
- **2026-04-21**: 소프트웨어 엔지니어링 결정에서 프롬프트 워딩(프레이밍, 앵커)이 AI 판단을 왜곡 [(원문)](https://arxiv.org/abs/2604.16756)
- **2026-04-21**: 맥락적 최소 쌍 생성과 n-gram 추상화로 LLM 출력의 사회 집단별 미묘한 언어적 편향 정량화 (arXiv:2604.17398) [(원문)](https://arxiv.org/abs/2604.17398)
