# Low-Resource Language AI

## 정의


## 주요 발전
- **2025-05-14**: FMSD-TTS: 티베트어 우-짱·아므도·캄 3개 방언에 대한 Few-shot 다중 화자 TTS, Speaker-Dialect Fusion + Dialect-Specialized Dynamic Routing Net [(원문)](https://arxiv.org/abs/2505.14351)
- **2024-11**: Pivot 언어 중심 대칭 parallel data 재사용 시 역방향 성능 저하(Directional Degeneration) 발생 [(원문)](https://arxiv.org/abs/2511.07003)
- **2024-05-10**: PL-MTEB 벤치마크: 30개 NLP 태스크, 12개 신규 폴란드어 데이터셋, 30개 다중언어 모델 평가 [(원문)](https://arxiv.org/abs/2405.10138)
- **2026-04-27**: BantuMorph transformer로 Proto-Bantu 어휘 복원, 14개 언어 728 명사/1525 동사 cognate 90.9% 검증 [(원문)](https://arxiv.org/abs/2604.22730)
- **2026-04-27**: Bantu 저자원 언어 Giriama(레이블 91개)의 cross-lingual transfer + clustering로 미기록 형태소 패턴 발견 [(원문)](https://arxiv.org/abs/2604.22723)
- **2026-04-26**: 특화 언어 모델 + 압축으로 제약된 하드웨어에서도 검증 가능한 QA 달성 [(원문)](https://arxiv.org/abs/2604.22095)
- **2025-07-03**: 다국어 LLM의 자기소비 훈련(자동 생성 데이터 재투입)으로 인한 언어형식·문법·문화적 뉘앙스의 점진적 손실 [(원문)](https://arxiv.org/abs/2507.03933)
- **2024-10-16**: 적응적 CFT 방식으로 저자원 언어 학습 가능, 기존 언어 성능 보존 가능 [(원문)](https://arxiv.org/abs/2410.16006)
- **2026-04-24**: 글로벌 사우스 언어 공동체는 인프라 제약이 가장 심하면서 다국어 지원 필요성도 높음 [(원문)](https://arxiv.org/abs/2604.21637)
- **2026-04-24**: 다국어 극성 탐지에서 cross-lingual augmentation (NLLB-200)은 형태론적 언어에서 성능 저하. 원본 아키텍처 선택이 더 효과적 [(원문)](https://arxiv.org/abs/2604.21370)
- **2026-04-22**: 힌디어 등 형태소 부자 언어의 LLM 평가 벤치마크 구축 필요 [(원문)](https://arxiv.org/abs/2604.18914)
- **2026-04-22**: Coptic-English 번역: Universal Dependencies 구문 정보(raw parser, verbalizations, targeted instructions)를 사전 기반 방법과 결합 시 SOTA 달성. Syntactic augmentation이 모든 모델 크기에서 이득 [(원문)](https://arxiv.org/abs/2604.18758)
- **2026-04-22**: 음차 변환이 스크립트 장벽 극복하여 어휘 중첩 증대, 저자원 언어 전이 학습 향상 [(원문)](https://arxiv.org/abs/2604.18722)
- **2026-04-20**: OmniVoice로 600+ 언어 TTS 지원, 저자원 언어 접근성 획기적 확대 [(원문)](https://www.aitimes.com/news/articleView.html?idxno=209553)
- **2025-11-10**: HPLT 3.0: 200개 언어, 30조 토큰 공개 프리트레이닝 데이터셋. 웹 크롤, 중복제거, 품질 필터링, PII 제거 전자동화 [(원문)](https://arxiv.org/abs/2511.01066)
- **2026-04-21**: Tibetan은 3대 방언(U-Tsang, Amdo, Kham)의 제한된 병렬 음성 corpus만 보유, TTS를 통한 dialectal speech 합성으로 학습 데이터 부족 해결 [(원문)](https://arxiv.org/abs/2509.18060)
- **2026-04-21**: LLM으로 수학 문제의 고유 명사·조직·통화를 자동 지역화하여 문화적 정확성 제고 [(원문)](https://arxiv.org/abs/2508.14913)
- **2026-04-21**: Telugu 감정분석에서 원어민 rationale 기반 감독으로 해석성과 공정성 향상 (TeSent dataset 9600만 화자 대상) [(원문)](https://arxiv.org/abs/2508.01486)
- **2026-04-21**: Actuality/Finesse 파라미터 추가로 Hindi 언어 맥락 특화 뉘앙스 처리 [(원문)](https://arxiv.org/abs/2507.05179)
- **2026-04-21**: Common Corpus에서 고자원 유럽 언어뿐 아니라 저자원 언어도 광범위하게 포함하여 언어 표현 다양성 확보 [(원문)](https://arxiv.org/abs/2506.01732)
- **2026-04-21**: 인도 NLP 종합 조사: 22개 공식 언어 기준 200+ datasets, 50+ benchmarks, 100+ models/tools. 스크립트 다양성과 데이터 부족 과제 정리 [(원문)](https://arxiv.org/abs/2604.18423)
- **2026-04-21**: Archi & Rutul 동캅카스 언어 ASR: 50-80분 데이터로 Whisper 대비 wav2vec2 경쟁력, 맞춤 음소 어휘로 성능 개선 [(원문)](https://arxiv.org/abs/2604.18204)
- **2026-04-21**: TriMix가 저자원 언어 LLM 적응에서 작은 모델의 LRL competence, 대형 모델의 스케일링 효과, 고자원 언어 과제 튜닝을 test-time logit 동적 융합하여, 저자원 언어 과제 주석 없이 달성 [(원문)](https://arxiv.org/abs/2604.18106)
- **2026-04-17**: 다국어 사전학습에서 번역 능력은 초기 토큰 복사 후 일반화 단계로 진행 [(원문)](https://arxiv.org/abs/2604.17633)
- **2026-04-20**: 문화 진화의 지적 자산으로서 저자원 언어를 LLM 기반 언어학·역사·문학 분석으로 보존 및 연구 [(원문)](https://arxiv.org/abs/2412.04497)
