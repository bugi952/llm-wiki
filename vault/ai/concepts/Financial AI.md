# Financial AI

## 정의


## 주요 발전
- **2026-02-01**: LLM을 behavioral parameters(loss aversion, herding, extrapolation) 측정 도구로 calibrate: baseline은 인간 벤치마크 대비 약화, profile-based calibration으로 보정 가능 (24,000 scenarios) [(원문)](https://arxiv.org/abs/2602.01022)
- **2026-04-27**: CB-APM(합의 기반 자산가격결정 모델): analyst consensus를 bottleneck으로 사용해 해석가능성-by-design 및 out-of-sample 예측성능 향상 [(원문)](https://arxiv.org/abs/2512.16251)
- **2025-02-17**: CausalGAN + SAC RL과 Qwen2.5-7B LLM을 통한 채권 수익률 예측 프레임워크 (신텍틱 데이터 12개 거시경제 변수 포함) [(원문)](https://arxiv.org/abs/2502.17011)
- **2026-04-21**: 한정 주문장 데이터로 유동성 침식 탐지 (신경망 vs 규칙 기반 +36% AUC 개선) [(원문)](https://arxiv.org/abs/2604.21993)
- **2026-04-25**: 지리정보 + 환경 데이터로 자동차보험 청구 빈도 예측 (GLM, GBT) — 공간 신호 활용 [(원문)](https://arxiv.org/abs/2604.21893v1)
- **2026-04-02**: FT-MDN-Transformer로 손실 회수율 예측에서 분포 편향 및 특성 공간 이질성 동시 처리 [(원문)](https://arxiv.org/abs/2604.02832)
- **2026-04-24**: Deep FinResearch Bench: 정성적 엄격성·정량적 정확성·주장 신뢰성 3차원 자동화 평가로 재무 조사 AI 벤치마킹 [(원문)](https://arxiv.org/abs/2604.21006)
- **2026-04-18**: AI 거래 에이전트의 프롬프트 개입을 통한 행동 메커니즘 조절로 시장 안정성 제어 가능성 입증 [(원문)](https://arxiv.org/abs/2604.18373)
- **2026-04-21**: MarketSenseAI: News/Fundamentals/Dynamics/Macro 4개 specialist agents의 LLM 시스템, S&P 500에서 +25.2% compound excess returns (p=0.003) [(원문)](https://arxiv.org/abs/2604.17327)
- **2026-04-21**: 고차원 자산 가격 모형에서 capacity sparsity 확대가 factor sparsity 발견을 가능하게 함 (nonlinear feature + basis pursuit로 complexity threshold 이상에서 out-of-sample 성능 우수) [(원문)](https://arxiv.org/abs/2604.17166)
- **2026-04-21**: LLM 기반 자율 트레이딩 에이전트의 일반화 능력은 특정 시장 패턴에 의존하며, MCQ 사전학습과 시뮬레이션 기반 평가 통합이 실제 거래 성능 검증에 효과적 [(원문)](https://arxiv.org/abs/2604.16862)
- **2026-04-20**: 결합분석(conjoint analysis) 시 LLM 생성 데이터로 실조사 비용·시간 절감, 편향 보정 기법 확립 [(원문)](https://arxiv.org/abs/2412.19363)
- **2026-04-19**: LLM 기반 거래 전략 자동 생성 및 백테스트 실행 능력 평가 [(원문)](https://arxiv.org/abs/2604.15151v1)
