# Materials Discovery AI

## 정의


## 주요 발전
- **2024-10-13**: 자동화된 결정체 구조 분석으로 결정학 소프트웨어 의존성 감소, 기하 패턴 인식 고도화 [(원문)](https://arxiv.org/abs/2410.13713)
- **2025-01-01**: Allen-Cahn 역학 기반 결정 성장을 Convolutional Recurrent NN 대리 모델로 시뮬레이션, 명시/암시 과포화도 조건화 비교 분석 [(원문)](https://arxiv.org/abs/2604.21753v1)
- **2025-02-01**: GFlowNet 훈련 동역학 시각화 시스템(GFlowState)으로 샘플링 궤적 및 상태 공간 탐색 해석 가능 [(원문)](https://arxiv.org/abs/2604.21830v1)
- **2025-03-04**: Explainable ML (permutation importance, SHAP) 기반 compact feature selection으로 5개 특징만 사용하고도 full model과 동등한 band gap 예측 성능 달성 [(원문)](https://arxiv.org/abs/2503.04492)
- **2026-04-24**: MLIP의 단거리 상호작용 모델은 실리카 유리의 FSDP 과다 예측, 장거리 주의 메커니즘으로 액체상 구조 개선 [(원문)](https://arxiv.org/abs/2604.21222)
- **2026-04-24**: MagMatLLM: 경쟁하는 물리 조건(자기성↔절연성) 동시 충족을 위한 LLM 기반 제약 조건 지도 생성 [(원문)](https://arxiv.org/abs/2604.21073)
- **2026-04-24**: DielecMIND: LLM 가설 생성 + 제1원리 계산 검증으로 데이터 부족 재료 발견 영역 개척 [(원문)](https://arxiv.org/abs/2604.21068)
- **2026-04-24**: LLM 기반 MOF 스케일업 예측(ESU-MOF 데이터셋)으로 discovery-to-deployment 간극 해소 (91.4% 정확도) [(원문)](https://arxiv.org/abs/2604.20899)
- **2026-04-21**: GFlowNets 기반 분자/재료 발견 과정의 샘플링 전략 가시화 [(원문)](https://arxiv.org/abs/2604.21830)
- **2026-04-21**: LLM의 분자 생성 창의성: 다중 화학·생물학적 제약 만족 하에서 non-obvious 해를 찾으면서도 국소 최적값 탈출을 위한 탐색 유지 [(원문)](https://arxiv.org/abs/2604.18031)
- **2026-04-21**: 데이터 curating, 스플릿 전략, 재현성 표준화가 분자 발견의 주요 과제로 식별 [(원문)](https://arxiv.org/abs/2604.16586)
- **2026-04-20**: Frontier 슈퍼컴퓨터 2048노드 기반 PaiNN 기초 모델로 다운스트림 과제 12개 전이 학습 가능 (화학적으로 다양한 작업) [(원문)](https://arxiv.org/abs/2604.15380)
