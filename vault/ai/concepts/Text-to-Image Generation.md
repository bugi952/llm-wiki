# Text-to-Image Generation

## 정의


## 주요 발전
- **2025-10-01**: VFM-VAE를 통해 의미론적으로 풍부한 토큰 생성, 확산 모델의 표현 학습 프로세스 시스템적 분석 [(원문)](https://arxiv.org/abs/2510.18457)
- **2026-04-24**: VAR 모델 distillation으로 one-step 이미지 초해상도 달성, 에러 누적 제거 (VARestorer) [(원문)](https://arxiv.org/abs/2604.21450)
- **2026-04-24**: StyleVAR: VAR 프레임워크로 이미지 스타일 전송을 다중 스케일 조건부 시퀀스 모델링으로 실현 [(원문)](https://arxiv.org/abs/2604.21052)
- **2026-04-24**: AI scientist 시스템의 end-to-end 논문 생성에서 과학 다이어그램 생성이 주요 bottleneck이며, 89,422개 규모의 schematic diagram 데이터셋(DiagramBank) 공개 [(원문)](https://arxiv.org/abs/2604.20857)
- **2026-04-21**: T2I 모델의 성별/인종 표현 불균형을 LLM 기반 공정성 정의로 재학습 없이 inference-time 완화 가능 [(원문)](https://arxiv.org/abs/2604.21036)
- **2025-05-16**: Frankentexts: 기존 인간 텍스트 조각 수천 개를 constraint(90% verbatim) 하에 조합. LLM이 combinatorial search 수행해 coherent narrative 생성 [(원문)](https://arxiv.org/abs/2505.18128)
- **2026-04-21**: Discrete Diffusion + GRPO로 T2I 생성 품질 대폭 개선. CFG-Free, Reduced-Step 효율화 기법 제시. [(원문)](https://arxiv.org/abs/2604.18518)
- **2026-04-21**: 장문 프롬프트 처리 시 구성적 프롬프트 분해로 각 컴포넌트별 노이즈 예측 후 에너지 기반 결합으로 단일 디노이징 단계 병합 [(원문)](https://arxiv.org/abs/2604.18258)
- **2026-04-21**: 3D autoregressive diffusion (3D-ARD+): multimodal token sequence와 diffusion을 통합하여 layout+shape co-generation [(원문)](https://arxiv.org/abs/2604.16552)
- **2026-04-21**: T2I bias 유형과 fairness 개념 체계화, 프롬프트 엔지니어링부터 확산 과정 조작까지 완화 전략 정리 [(원문)](https://arxiv.org/abs/2604.16516)
- **2026-04-21**: 2026-04 CSF (Compositional Semantic Fingerprinting): 배포된 T2I 모델의 미세조정 출처를 쿼리만으로 추적. 6개 모델군 13개 변형에서 검증됨 [(원문)](https://arxiv.org/abs/2604.16363)
- **2026-04-04**: 2026-04-04 정체불명의 고성능 이미지 생성 모델(덕트 테이프)이 LM Arena에 등장, 기존 벤치마크 기록 경신 [(원문)](https://www.aitimes.com/news/articleView.html?idxno=209468)
- **2026-04-20**: 이미지 내 텍스트 자동 번역 시 원본 디자인 요소를 유지하는 '텍스트 속성 인식' 기술 출현 [(원문)](https://www.aitimes.com/news/articleView.html?idxno=209500)
