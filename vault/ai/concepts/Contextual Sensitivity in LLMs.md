# Contextual Sensitivity in LLMs

## 정의


## 주요 발전
- **2025-05-01**: 쿼리의 언어 선택이 LLM의 맥락 이해 능력에 유의미한 영향을 미치는 동적 언어 선택 문제 제시 [(원문)](https://arxiv.org/abs/2505.14990)
- **2026-04-27**: 프롬프팅 스타일(명령형 vs 샘플 기반)이 다르더라도 작업별 어텐션 헤드(lexical task heads)가 공유되어 동일 기저 메커니즘 사용 [(원문)](https://arxiv.org/abs/2604.22027)
- **2026-02-03**: nonce words의 음운상징성이 LLM 임베딩의 interoceptive norm과 체계적 연관성 보유 [(원문)](https://arxiv.org/abs/2602.00469)
- **2026-04-22**: 4개 태스크·9개 데이터셋 기반 LLM 문맥 이해 벤치마크 제안 [(원문)](https://machinelearning.apple.com/research/llm-context-understanding)
- **2025-10-19**: LLM은 영문 대화에서 75-80% 사회적 추론 정확도, 한국어는 58-69% (SCRIPTS 1.1k) [(원문)](https://arxiv.org/abs/2510.19028)
- **2026-04-21**: LLM의 context 민감도는 task의 지식 수요와 conflict 그럴듯함에 의해 조절되는 task 특화 현상 (2026-04-21) [(원문)](https://arxiv.org/abs/2506.06485)
- **2026-04-21**: 신경 언어 모델은 설정된 surprisal theory로는 정원경로 효과를 완전히 설명할 수 없으며, 신택스 구조 해석에서 인간과 차이 있음 [(원문)](https://arxiv.org/abs/2604.18293)
- **2026-04-21**: x1: 언어별 적응형 추론이 수학/문화 작업에서 성능 향상. 단일 지배언어 추론보다 이득 [(원문)](https://arxiv.org/abs/2604.16917)
- **2026-04-21**: Emoji는 WordPiece [UNK] 토큰 매핑으로 입력 신호 파괴 (93.6% 사례 포함), slang은 in-vocabulary로 최소 저하 (≤1.1pp) [(원문)](https://arxiv.org/abs/2604.16787)
