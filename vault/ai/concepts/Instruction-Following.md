# Instruction-Following

## 정의


## 주요 발전
- **2026-04-21**: 사용자 프롬프트를 완전한 의도의 표현으로 가정하는 기존 패러다임의 한계 [(원문)](https://arxiv.org/abs/2604.21827)
- **2026-04-21**: 멀티모달 정책의 복잡도 증가에 따라 모델 파라미터 내재화 방식으로 추론 비용 최소화 및 정책 준수 신뢰도 상향 [(원문)](https://arxiv.org/abs/2510.09474)
- **2025-10-07**: IASC 에이전틱 시스템으로 각 언어 성분별 모듈형 프롬프트 세트와 자동 피드백 정제 가능 [(원문)](https://arxiv.org/abs/2510.07591)
- **2026-04-21**: user/assistant 역할 태그의 훈련 데이터 비대칭이 inductive bias 유발 [(원문)](https://arxiv.org/abs/2508.15815)
- **2026-04-21**: LLM은 일관되고 설득력 있는 대화 유지 우수하나, 논증 구조와 전제 존재 같은 깊은 이해는 부족. AI 개입 인식 시 인간의 비판적 사고 증가 [(원문)](https://arxiv.org/abs/2507.01936)
- **2024-10-05**: Mixup 방식으로 높은 confidence 데이터의 과적합, 낮은 confidence 데이터의 일반화 어려움 동시 해결 [(원문)](https://arxiv.org/abs/2410.05248)
- **2026-04-21**: Inter-Prompt Reliability (IPR): 의미상 동등한 프롬프트 변형에 대한 LLM 일관성 격차, TREC 35% vs Politifact 85% [(원문)](https://arxiv.org/abs/2604.16413)
- **2026-04-20**: Instruction granularity가 agent 성능에 U-shaped 곡선 생성: 세부 지침과 고수준 목표 모두에서 최고 성능 [(원문)](https://arxiv.org/abs/2604.17019)
- **2025-11-01**: 한쪽 대화 복원 시 미래 턴 정보와 발화 길이 힌트가 정확도 향상에 효과적 [(원문)](https://arxiv.org/abs/2511.03056)
- **2026-04-20**: PLUM 코퍼스: 정중한 프롬프트가 응답 품질을 ~11% 개선, 언어와 모델에 따라 편차 발생 [(원문)](https://arxiv.org/abs/2604.16275)
- **2026-04-20**: 이질 LLM 다중 앙상블의 모델간 불일치를 기반으로 명령어 자동 정제 (DiZiNER). NER에서 zero-shot SOTA 달성 [(원문)](https://arxiv.org/abs/2604.15866)
- **2026-04-19**: 정보 추구 QA에서 LLM은 인간 커뮤니티와 달리 담화 전략의 다양성 부족 → 과도하게 광범위하게 응답하는 경향 [(원문)](https://arxiv.org/abs/2604.15140v1)
