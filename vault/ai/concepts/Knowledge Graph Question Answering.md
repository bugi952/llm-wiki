# Knowledge Graph Question Answering

## 정의


## 주요 발전
- **2026-04-22**: STEM(Structure-Tracing Evidence Mining) 프레임워크로 KG 구조적 이질성 해결. Semantic-to-Structural Projection으로 쿼리를 원자적 관계 주장으로 분해 후 adaptive query schema 구성 [(원문)](https://arxiv.org/abs/2604.22282)
- **2026-04-25**: 이벤트 이해를 통한 문서 요약 및 긴급 상황 의사결정 지원 (EVENT5Ws 벤치마크) [(원문)](https://arxiv.org/abs/2604.21890v1)
- **2026-04-24**: SocraticKG는 5W1H 기반 QA expansion으로 KG 구성의 factual coverage와 정보 손실 tradeoff 해결 [(원문)](https://arxiv.org/abs/2601.10003)
- **2026-04-24**: 관계성 학습 기반 재순위(AAR): HotpotQA Recall@5 83.1% → 91.6% (+8.6%), 어려운 질문 +28.5% [(원문)](https://arxiv.org/abs/2604.20850)
- **2026-04-21**: Triple 기반 entity linking의 relation extraction 오류 문제를 원자 팩트 표현으로 해결 [(원문)](https://arxiv.org/abs/2604.20844)
- **2026-04-24**: GS-Quant: granular semantic codebook로 LLM-KGC modality gap 해결 (coarse-to-fine hierarchical structure) [(원문)](https://arxiv.org/abs/2604.21649)
- **2026-04-24**: GRISP: 자연언어 SPARQL 스켈레톤 생성 후 반복적 IRI 선택으로 placeholder를 지식 그래프 항목으로 치환 [(원문)](https://arxiv.org/abs/2604.21133)
- **2026-04-22**: LogosKG는 하드웨어 정렬 설계로 대규모 KG 다중 홉 검색의 효율성 대폭 향상 [(원문)](https://arxiv.org/abs/2604.18913)
- **2025-12**: KG-기반 QA에 이미지 및 공간적 단서 통합해 다중 모달리티 추론 지원 [(원문)](https://arxiv.org/abs/2512.20626)
- **2025-10-15**: 2025: RL 기반 엔드투엔드 KG 구성으로 RAG 성능 자동 최적화 기법 제시 [(원문)](https://arxiv.org/abs/2510.15339)
- **2025-05-15**: HopWeaver는 인간 주석 데이터셋 수준의 품질로 다중 홉 질문을 자동 합성, 비용 절감 (arXiv:2505.15087) [(원문)](https://arxiv.org/abs/2505.15087)
- **2024-11-12**: NumCoKE: symbolic triples + numerical attributes(length, weight 등)의 ordinal-aware 추론을 MoE·contrastive learning으로 구현 [(원문)](https://arxiv.org/abs/2411.12950)
- **2026-04-21**: Entity-first multi-hop 탐색을 query time에 mention graph RDF로 수행하는 실시간 네비게이션 시스템 구현 [(원문)](https://arxiv.org/abs/2604.17056)
- **2026-04-16**: GNN 기반 phenotype discovery + causal inference로 KG 자동 확장 가능, Pareto-optimal selection으로 novelty-validation 균형 [(원문)](https://arxiv.org/abs/2604.16982)
- **2025-04-20**: 구조화된 데이터(표)에 대한 쿼리 답변 능력 벤치마킹 [(원문)](https://arxiv.org/abs/2505.19563)
- **2026-04-20**: 지식 그래프와 LLM의 통합으로 구조화된 추론 및 검색 성능 향상 [(원문)](https://arxiv.org/abs/2604.15951)
