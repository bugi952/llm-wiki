# Reasoning Trace Reliability

## 정의


## 주요 발전
- **2026-04-22**: 자가 교정은 제1순서가 아닌 제2순서 평가 신호에 의존해 committed response와 독립적으로 에러 감지 [(원문)](https://arxiv.org/abs/2604.22271)
- **2026-04-27**: RLVR 훈련이 작업 정확도를 올려도 CIR(인과적 중요성)과 SR(충분성) 개선을 보장하지 않음 [(원문)](https://arxiv.org/abs/2604.22074)
- **2025-10-07**: Choices-only 입력에서도 test-time reasoning이 도움이 되나, 추론 길이와 성공률 무관 - shortcut vs 정당한 추론 구분 필요 [(원문)](https://arxiv.org/abs/2510.07761)
- **2026-04-21**: 계획 기반 논리 문제로 생성된 CoT 코퍼스로 추론 단계 신뢰도 평가 모델 강화 [(원문)](https://arxiv.org/abs/2604.17957)
- **2026-04-21**: 같은 모델, 입력, 기본 프롬프트에서 두 트레이스의 차이는 순수하게 추론 전략과 에러 피드백을 반영하여 대조 학습에 최적화된 신호 제공 (2026-04-21) [(원문)](https://arxiv.org/abs/2604.17937)
