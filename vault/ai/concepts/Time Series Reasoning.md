# Time Series Reasoning

## 정의


## 주요 발전
- **2026-04-27**: SymbolBench: multivariate symbolic regression, Boolean network inference, causal discovery 포함하는 시계열 symbolic reasoning 벤치마크. LLM + genetic programming 하이브리드가 closed-loop symbolic reasoning system 구성 [(원문)](https://arxiv.org/abs/2508.03963)
- **2025-12**: Concurrence: 분류기를 이용한 정렬/미정렬 세그먼트 구별로 시계열 의존성 측정 [(원문)](https://arxiv.org/abs/2512.16001)
- **2026-04-24**: Forecast AC Score는 accuracy와 temporal consistency(forecast stability)를 동시에 최적화하는 새로운 평가 패러다임 [(원문)](https://arxiv.org/abs/2601.10863)
- **2025-11-18**: TimePre: MLP+MCL 기반 확률적 시계열 예측. Stabilized Instance Normalization으로 catastrophic hypothesis collapse 해결. 샘플링 방식 대비 수십 배 빠른 추론 [(원문)](https://arxiv.org/abs/2511.18539)
- **2025-05-20**: TQA 서베이 발행 — 시간 제약 기반 QA 체계화 [(원문)](https://arxiv.org/abs/2505.20243)
- **2026-04-21**: 고레벨 이벤트 추론의 다항식 시간 복잡도 보장을 위한 제약 조건 식별 [(원문)](https://arxiv.org/abs/2604.21793)
- **2026-04-21**: 환자 표현 학습에서 observation pattern을 잠재 상태 추론의 신호로 활용 [(원문)](https://arxiv.org/abs/2604.21235)
- **2025-11-10**: TSVer 벤치마크: 304개 실제 클레임 × 400개 시계열 데이터로 시간-수치 추론 평가. 41개 팩트체킹 기관 소스 [(원문)](https://arxiv.org/abs/2511.01101)
- **2026-04-21**: CaTS-Bench: 11개 도메인의 1,746개 인간 작성 캡션 기반 시계열 캡셔닝 벤치마크 [(원문)](https://arxiv.org/abs/2509.20823)
- **2026-04-21**: LLM의 slow thinking으로 시계열 예측 성능 향상 (arXiv:2506.10630) [(원문)](https://arxiv.org/abs/2506.10630)
- **2025-01-12**: 불완전한 센서 배치에서 미관측 지점의 교통 상태 예측 가능 (귀납적 접근) [(원문)](https://arxiv.org/abs/2501.12281)
- **2026-04-21**: 에이전트 기반 특성 가중치 적응으로 정확도 향상 및 해석 가능성 제공, 인구/지역별 이전성 확보 [(원문)](https://arxiv.org/abs/2604.17419)
- **2026-04-21**: SPaRSe-TIME: Saliency-Memory-Trend 분해 기반 저순위 시계열 모델링으로 계산 비용 대폭 감소 [(원문)](https://arxiv.org/abs/2604.17350)
- **2026-04-21**: 1D 시계열을 시간·주파수·2D 비전 공간으로 디엔탱글먼트해 표현 병목 해결 [(원문)](https://arxiv.org/abs/2604.16748)
- **2026-04-21**: CAARL은 자동회귀 분해, 시간 종속성 그래프, 자연언어 직렬화를 통해 공진화 시계열의 해석 가능한 예측 제공 [(원문)](https://arxiv.org/abs/2604.18305)
- **2026-04-21**: LLaTiSA: 시각화 패턴과 정밀 캘리브레이션 수치 테이블 결합으로 VLM의 시간적 지각력 향상 (HiTSR 83k 샘플, 검증된 CoT 경로) [(원문)](https://arxiv.org/abs/2604.17295)
- **2025-07-03**: PAC learning 기반의 Sequential Regression (randomized SINDy) 제안, 확률 분포 학습으로 동적 데이터 예측 [(원문)](https://arxiv.org/abs/2507.03759)
- **2026-04-20**: 추천 시스템에서 분 단위 상호작용과 월 단위 흐름을 구분하는 사용자 개인화 시간 근접성 학습 [(원문)](https://arxiv.org/abs/2604.15581)
- **2026-04-20**: GMM 기반 확률적 교통 예측으로 스토캐스틱 불확실성 모델링 [(원문)](https://arxiv.org/abs/2604.16084)
- **2026-04-20**: 가역 잔여 정규화로 공간-시간 분포 변화의 적응적 대응 [(원문)](https://arxiv.org/abs/2604.15838)
- **2026-04-20**: 시공간 무작위 보행과 병렬화 시간 합성곱으로 구조적 시계열 분석 고도화 [(원문)](https://arxiv.org/abs/2604.15833)
- **2026-04-20**: 예측 불확실성 정량화로 의사결정 신뢰도 평가 가능. 다단계 미래 예측의 확률 구간 제공 [(원문)](https://arxiv.org/abs/2604.15791)
- **2026-04-20**: 시점 프로세스 예측, Markov 점프 프로세스 추정, 시계열 보간을 LLM 진화 탐색으로 자동 알고리즘 발견 [(원문)](https://arxiv.org/abs/2604.15787)
- **2026-04-20**: 다중 소스 시계열 데이터 결합(셀룰러 + 센서)으로 vehicle-category별 교통 흐름 추론 가능 [(원문)](https://arxiv.org/abs/2604.15782)
