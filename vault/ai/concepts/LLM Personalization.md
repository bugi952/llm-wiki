# LLM Personalization

## 정의


## 주요 발전
- **2026-04-27**: 신경 기호적 검증기로 발달·심리학적 제약 강제, 계층화 샘플링 + 의미 중복제거로 모드 붕괴 방지, 교육 LLM 인프라 다양성 확보 [(원문)](https://arxiv.org/abs/2603.04855)
- **2025-10**: Survey Response Generation: 8개 방법론 중 Restricted Generation이 개별·하위집단 수준 일치도에서 최고 성능 [(원문)](https://arxiv.org/abs/2510.11586)
- **2025-08-10**: VAC 프레임워크: 사용자 프로필·질문 기반 자연언어 피드백으로 개인화 전략 내재화, 반복적 개선 가능 [(원문)](https://arxiv.org/abs/2508.10695)
- **2026-04-27**: 어휘 복잡도 제어로 역어휘 비율 낮추고 자연성·교육 효과 동시 증대 [(원문)](https://arxiv.org/abs/2604.22542)
- **2026-04-26**: 학습 없이 추론 시 선호도 헤드 대비로 사용자 정렬 출력 증폭 가능한 제어 메커니즘 [(원문)](https://arxiv.org/abs/2604.22345)
- **2026-04-22**: LLM 재작성은 함수어·축약형·1인칭 대명사 감소, 어휘다양성·단어길이·구두점 증가로 일관된 스타일 정규화 야기 [(원문)](https://arxiv.org/abs/2604.22142)
- **2026-04-22**: LLM 기반 토픽 생성으로 조직별 도메인 특화 토픽 세분화 실현 [(원문)](https://arxiv.org/abs/2604.18919)
- **2025-06-15**: Prefix와 입력 프롬프트의 기여도 트레이드오프 문제 해결로 개인화 성능 향상 [(원문)](https://arxiv.org/abs/2506.13674)
- **2024-12-08**: HyRe: 앙상블 헤드의 베이지안 재가중치화로 사용자 선호도 1-5개 예제만으로 실시간 맞춤화 (계산 오버헤드 <1%) [(원문)](https://arxiv.org/abs/2412.08812)
- **2026-04-21**: parameter-efficient fine-tuning으로 저자원 언어 사법 도메인 개인화 실현. CLM + synthetic instruction-tuning 조합 최고 성능 [(원문)](https://arxiv.org/abs/2604.18041)
- **2026-04-20**: PRefine: 사용자 선호도를 진화하는 가설로 표현. 생성-검증-정제 루프로 세션 간 제약 추출·재활용. 전체 이력 프롬팅의 1.24% 토큰으로 도구 호출 정확성 향상 [(원문)](https://arxiv.org/abs/2604.17886)
- **2026-04-21**: 5개 언어(영어, 독일어, 힌디어, 네팔어, 우르두어) × 4개 deployed LLM에서 12개 pragmatic feature (경의, 개인-집단 프레이밍, 불확실성 관리 등) 측정 [(원문)](https://arxiv.org/abs/2604.17718)
- **2026-04-21**: HorizonBench: 6개월 대화 이력(~4,300 턴, ~163K 토큰)에서 진화하는 선호도 추적으로 메모리/장컨텍스트/마음이론 모델 평가 [(원문)](https://arxiv.org/abs/2604.17283)
