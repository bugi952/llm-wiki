# Small Language Models

## 정의


## 주요 발전
- **2026-04-21**: 생성기 모델 크기보다 정제기(refiner) 능력이 코드 생성 품질에 더 큰 영향 [(원문)](https://arxiv.org/abs/2604.21950)
- **2026-04-21**: 3-9B 모델의 수치형(0-100) 신뢰도 표현 모두 심리측정 유효성 미달 (7/7 무효, 천정효과 91.7%) [(원문)](https://arxiv.org/abs/2604.22215)
- **2024-11-11**: 연합 프레임워크로 도메인 특화 미세조정 시 LLM 급 성능 달성 가능 [(원문)](https://arxiv.org/abs/2411.11707)
- **2026-04-24**: SLM의 골격 생성과 리스트와이즈 재랭킹 이중 학습으로 제약 조건 준수 하의 정확한 쿼리 구성 가능 [(원문)](https://arxiv.org/abs/2604.21133)
- **2025-10-09**: ReTraceQA: 14-24% SLM이 추론 논리는 틀렸으나 최종 답은 맞음 - answer-only metric으로 능력 과평가 발견 [(원문)](https://arxiv.org/abs/2510.09351)
- **2025-10-07**: 도구 사용 시 주요 실패: schema misalignment로 훈련되지 않은 도구명 할루시네이션 및 파라미터 식별 오류 [(원문)](https://arxiv.org/abs/2510.07248)
- **2026-04-21**: 어휘 임베딩과 LM head가 메모리 발자국의 주요 부분 차지, 동적 선택으로 최적화 가능 [(원문)](https://arxiv.org/abs/2508.15229)
- **2026-04-21**: RLVR 후 그래프/공간 추론 downstream task 성능 향상, compute 부족 환경서도 유효 (arXiv 2604.18381) [(원문)](https://arxiv.org/abs/2604.18381)
- **2026-04-21**: Fine-tuned SLM (3-4B)은 구조적으로 다른 그래프 패밀리에서도 ordinal consistency 유지하며, 학습 범위보다 큰 입력에서도 성능 유지 [(원문)](https://arxiv.org/abs/2604.18092)
- **2026-04-21**: 실데이터 고정 상태에서 증강 스케일 증가로 작은 모델이 큰 모델 수준 성능 달성 [(원문)](https://arxiv.org/abs/2604.18087)
- **2026-04-21**: 강력한 SLM일수록 LLM 호출을 자율적으로 감소시키는 scaling effect 확인; 강력한 LLM은 더 정보 풍부한 피드백으로 상호작용 효율성 증가 [(원문)](https://arxiv.org/abs/2604.17827)
- **2026-04-21**: 2026-04: 베트남어 수학 추론 데이터셋(Vi-S1K)으로 SLM 추론 갭 분석, Qwen3-1.7B SFT 후 77% 개선 [(원문)](https://arxiv.org/abs/2604.17794)
- **2026-04-21**: SGDe: 기업 배포 시 자가 수정 불가능 문제를 교사-학생 프레임워크로 해결(3샘플 수렴) [(원문)](https://arxiv.org/abs/2604.17450)
- **2026-04-21**: edge-native SLMs의 System 2 reasoning은 high-risk governance 환경에서 역효과 가능, 도메인별 compute 최적화 필요 [(원문)](https://arxiv.org/abs/2604.16913)
- **2026-04-20**: 모바일 엣지에서 CPU-GPU 동적 주파수 스케일링(DVFS) 환경의 레이턴시 편차를 고려한 추론 지연 추정 최적화(FLAME) [(원문)](https://arxiv.org/abs/2604.15357)
- **2026-04-20**: CoT 증류에서 교사의 단계별 핵심정보 어텐션을 Mixture-of-Layers로 전이하여 소형 모델의 구조화된 추론 학습 (arXiv:2604.15701) [(원문)](https://arxiv.org/abs/2604.15701)
