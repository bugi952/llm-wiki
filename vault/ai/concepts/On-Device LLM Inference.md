## 주요 발전
- **2026-04-27**: 장거리 이동(비행기) 등 네트워크 단절 상황에서 로컬 LLM 실행 검증 [(원문)](https://news.ycombinator.com/item?id=47921064)
- **2025-10**: Trainium의 이기종 아키텍처: 메모리 계층 최적화로 데이터 이동 최소화, SRAM 대역폭 극대화, 행렬 전치 비용 회피 [(원문)](https://arxiv.org/abs/2510.25977)
- **2026-01-20**: dLLM 전용 NPU 설계로 AR 기반 가정을 벗어난 하드웨어 아키텍처 제시 [(원문)](https://arxiv.org/abs/2601.20706)
- **2026-04-24**: 클라우드-엣지 하이브리드 KV 스트리밍으로 TTFT 1.3-5.1배 단축, 에너지 소비 1.5-3.3배 감소 [(원문)](https://arxiv.org/abs/2604.21231)
- **2026-04-24**: 다국어 에지 배포는 기술적 요구사항 상충으로 통합 연구 필요한 미개척 분야 [(원문)](https://arxiv.org/abs/2604.21637)
- **2026-04-24**: 하이퍼커넥션을 통한 잔차 스트림 확장으로 메모리 풋프린트 제약 환경 최적화 [(원문)](https://arxiv.org/abs/2604.21254)
- **2026-04-24**: FairyFuse: Ternary weights (-1,0,+1)로 CPU에서 곱셈 없는 LLM 추론 실현 [(원문)](https://arxiv.org/abs/2604.20913)
- **2026-04-21**: Apple Silicon의 ANE를 통해 MoE prefill 단계 추론 가속. CPU/GPU 폴백 경로로 호환성 유지. [(원문)](https://arxiv.org/abs/2604.18788)
- **2026-04-21**: 위성 영상 수집 체인에서 온보드 ML로 전송 우선순위 결정 (EarthSight) [(원문)](https://arxiv.org/abs/2511.10834)
- **2025-08-01**: 우주 탐사체의 극한 환경(전력/열/메모리 제약)에서 INT8 양자화 및 다중센서 융합 기반 추론 필수 [(원문)](https://arxiv.org/abs/2508.18025)
- **2026-04-21**: 클러스터링 벡터 양자화로 PIM 기반 KV 캐시 효율 개선, 장문맥 시나리오에서 메모리 초과 문제 해결 [(원문)](https://arxiv.org/abs/2604.18137)
- **2026-04-21**: 신경형 칩 기반 온디바이스 추론: 극소 SWaP(Size, Weight, Power)로 엣지 AI 배포 가능성 입증 (2026-04) [(원문)](https://arxiv.org/abs/2604.16474)
- **2026-04-21**: Fine-tuning과 inference의 통합 배포로 inference 품질 단계적 개선 [(원문)](https://arxiv.org/abs/2604.16400)
- **2026-04-21**: GSQ는 GPTQ/AWQ(단순)와 QTIP/AQLM(정확)의 간극 해소. 구현 난이도 낮으면서 vector 방법 수준 성능 [(원문)](https://arxiv.org/abs/2604.18556)
- **2026-04-21**: PhysioLite: μNPU 호환 ECG/EMG 신호 분석 모델. Wavelet filter + CPU 오프로드로 370KB(8-bit) 크기, SOTA 대비 동등 성능 [(원문)](https://arxiv.org/abs/2604.18067)
- **2026-04-21**: 비상주 LoRA 어댑터 가중치 페이징 지연을 완화하기 위해 캐싱-라우팅을 2단계 문맥 밴딧으로 공동 최적화 가능 [(원문)](https://arxiv.org/abs/2604.16583)
- **2026-04-20**: 회절 광학 신경망(DONN)과 홀로그래픽 간섭 학습(HIBL)으로 수동 광학 소자 내 실시간 추론 구현 [(원문)](https://arxiv.org/abs/2604.15364)
- **2026-04-20**: CPU-GPU 비동기 커플링에서 단순 분석적 스케일링이 실패하므로, 주파수-인식(frequency-aware) 레이턴시 모델링 필요 [(원문)](https://arxiv.org/abs/2604.15357)
