# Brain-Computer Interfaces

## 정의


## 주요 발전
- **2026-01-19**: 크로스세션 신경 신호 디코딩을 위한 작업조건부 잠재정렬(TCLA) 기법 제시 (arXiv:2601.19963) [(원문)](https://arxiv.org/abs/2601.19963)
- **2026-04-22**: 근전도(EMG) 신호 기반 고차원 손가락 운동 연속 추정으로 의수/AR·XR 인터페이스 제어 가능 [(원문)](https://arxiv.org/abs/2604.22499)
- **2025-12**: 멀티모달 뇌 해독(fMRI → 자연언어)에서 soft-ROI fusion 기반 BrainROI 모델로 SOTA 달성 [(원문)](https://arxiv.org/abs/2512.20249)
- **2026-04-21**: 신경모방 지각 시뮬레이션(BI-Cap)으로 뇌 시각 처리를 탑-다운 모델링. 적응형 흐림 조절 + 불확실성 기반 잠재 표현으로 신경 활동 비정상성 완화 (arXiv:2604.17927) [(원문)](https://arxiv.org/abs/2604.17927)
- **2026-04-21**: iPhoneme: ConformerXL 기반 brain-to-text, gaze-assisted phoneme input으로 Midas touch problem 해결; ALS dysarthria 환자 음성 복원 [(원문)](https://arxiv.org/abs/2604.16441)
- **2026-04-21**: Brain-CLIPLM: 2단계 프레임워크로 EEG→텍스트 디코딩을 의미 추출 + 검색 기반 재구성으로 분해 [(원문)](https://arxiv.org/abs/2604.16370)
- **2026-04-20**: 폐쇄루프 압전식 촉각 디스플레이로 형상·강성·마찰의 3차원 신호를 500Hz 갱신율, 5mm 변위로 고정밀 렌더링 [(원문)](https://arxiv.org/abs/2603.13829)
- **2026-04-20**: 시각적 상상 콘텐츠의 fMRI 재구성에 확산 모델 기반 잠재 함수 정렬 적용 → 적은 감독 데이터로 고성능 달성 [(원문)](https://arxiv.org/abs/2604.15374)
- **2026-04-17**: EMG 신호의 나이, BMI 등 개인 특성에 따른 변동이 신경 인터페이스의 성능 일반화를 제한하며, 보조기구 공정한 배포를 저해 [(원문)](https://arxiv.org/abs/2604.14460)
- **2026-04-17**: Pretrained EEG 모델과 기하학적 제약을 이용한 scalp/intracranial EEG 신호 정렬 기술 [(원문)](https://arxiv.org/abs/2604.14202)
- **2026-04-17**: 파운데이션 모델 기반 BCI는 높은 정확도 제공하지만 임베디드 배포를 위해선 지식 증류 필수 [(원문)](https://arxiv.org/abs/2604.15016)
