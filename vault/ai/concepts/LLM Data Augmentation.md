# LLM Data Augmentation

## 정의


## 주요 발전
- **2026-04-27**: 제품 리뷰에서 LLM으로 감각 속성(색상, 향기 등) 구조화 추출 후 학생 트랜스포머로 증류하여 임베딩 생성 [(원문)](https://arxiv.org/abs/2603.02709)
- **2026-04-22**: 동적 텍스트 획득: 웹+LLM으로 미지/신규 엔티티의 도메인 분류기 구축 가능 (엔티티명+라벨만으로) [(원문)](https://arxiv.org/abs/2604.22325)
- **2026-04-21**: COT 프롬프트로 저품질 직업 설명을 다듬고 재작성하여 모델 성능 향상 [(원문)](https://arxiv.org/abs/2604.21264)
- **2025-10-08**: CAPC-CG: 중국 중앙정부 정책 문서 1949-2023년, 3.3M 파라그래프 유닛, 5단계 모호성 분류 (Fleiss κ=0.86) [(원문)](https://arxiv.org/abs/2510.08986)
- **2024-08-11**: LLM으로 클래스 설계 및 검색 기반 데이터 수집 자동화, 100만+ 이미지 의류 데이터셋 생성 [(원문)](https://arxiv.org/abs/2408.11338)
- **2026-04-21**: Paper2Data - LLM-driven 데이터 추출 파이프라인이 15,000+ Nature publications에서 60,000개 urban datasets을 90% recall로 자동 추출·구조화 [(원문)](https://arxiv.org/abs/2604.16317)
- **2026-04-21**: 무선 통신 분야에서 in-context learning으로 합성 RF 데이터 생성, modulation/interference 분류 개선 [(원문)](https://arxiv.org/abs/2604.17770)
- **2026-04-21**: 도메인 특화: 5단계 프롬프트 파이프라인으로 채용공고-이력서 양성/하드 네거티브 샘플 합성 [(원문)](https://arxiv.org/abs/2604.17738)
